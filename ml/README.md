# Персонализация новостей

Модуль читает данные компаний из `data/sample/`, строит бизнес-профиль и ранжирует переданные новости с учетом компании и роли CEO/CFO. Каждая оценка сопровождается объяснением; неизвестные значения сохраняются.

| Файлы | Назначение |
|---|---|
| `data_access.py`, `dataset.py` | Чтение, очистка и индексация CSV, чтобы не загружать таблицы при каждом запросе |
| `company_profile.py` | Профиль компании, платежные агрегаты и деловые связи |
| `news_processing.py`, `deduplication.py` | Признаки новостей и объединение повторных публикаций |
| `ranking.py`, `config.py` | Объяснимые оценки и настройки весов, тем и отраслей |
| `contracts.py`, `integration.py` | Проверка форматов и преобразование данных бэкенда |
| `eda.py`, `validate_dataset.py`, `evaluation.py` | Проверка качества данных, профилей и ранжирования |
| `__init__.py` | Экспорт основных функций модуля |

Таблицы индексируются один раз для быстрого получения профилей. Рейтинг рассчитывается по прозрачным правилам; веса хранятся отдельно, чтобы их было удобно настраивать. Подключение модуля к API выполняется на стороне бэкенда.

Python 3.12, зависимости общие с проектом. Тесты находятся в `test/`; запуск из корня:

```bash
python -m pytest -q
```
